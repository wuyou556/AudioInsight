# AudioInsight 前端使用指南

## 快速启动

### 方法 1: 直接打开（推荐用于开发测试）

直接在浏览器中打开 `frontend/index.html` 文件即可。

**注意：** 由于浏览器 CORS 限制，需要后端 API 支持跨域请求。

### 方法 2: 使用简单 HTTP 服务器

在 `frontend` 目录下运行：

```bash
# Python 3
python -m http.server 8080

# 或者使用 Node.js (需要先安装 http-server)
npx http-server -p 8080
```

然后访问 http://localhost:8080

## 后端 API 配置

前端默认连接到 `http://localhost:8000`。

如果后端运行在不同地址，修改 `index.html` 中的 `API_BASE` 变量：

```javascript
const API_BASE = 'http://your-api-host:port';
```

## 功能说明

### 📤 上传录音
1. 切换到"上传录音"标签页
2. 点击上传区域或拖拽音频文件
3. 支持格式：MP3, WAV, M4A, AAC
4. 上传后自动切换到录音列表

### 📋 我的录音
1. 查看所有已上传的录音
2. 显示文件信息和处理状态：
   - ⏳ 等待中 (pending)
   - 🎙️ 转写中 (transcribing)
   - ✨ 摘要中 (summarizing)
   - ✅ 完成 (done)
   - ❌ 失败 (failed)
3. 支持分页浏览
4. 每页显示 10 条记录

### 👁️ 查看详情
1. 点击录音卡片的"查看"按钮
2. 查看完整的转写文本
3. 查看智能摘要：
   - 📝 摘要文本
   - 🔑 关键要点
   - 📋 待办事项
4. 如果任务失败，可以点击"重试"按钮

### 🗑️ 删除录音
1. 点击录音卡片的"删除"按钮
2. 确认后删除（不可恢复）
3. 会同时删除录音文件和所有关联任务

## 后端 CORS 配置

如果遇到跨域问题，需要在后端添加 CORS 支持：

```python
# app/main.py
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 生产环境应限制具体域名
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 常见问题

### Q: 上传后看不到录音？
A: 稍等片刻，点击"我的录音"标签页刷新列表。

### Q: 状态一直显示"处理中"？
A: 手动刷新页面或切换标签页重新加载。

### Q: 删除失败？
A: 检查后端服务是否正常运行，查看浏览器控制台错误信息。

### Q: 看不到转写结果？
A: 只有状态为"完成"的任务才会显示转写和摘要结果。
